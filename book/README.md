# The White T-Shirt Guide to Persuasion, Branding, and Design

This mini textbook is a short, practical introduction to how design shapes attention, meaning, and action. Each chapter uses the same recurring example — a plain white T-shirt — to show how one ordinary physical object can be framed in very different ways.

The book is meant for first-year students who want to understand design as more than style. It treats design as a way of shaping interpretation, building trust, telling stories, and helping people make choices.
